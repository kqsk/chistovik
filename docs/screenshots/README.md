# Скриншоты для README

Положите сюда PNG с такими именами (ширина ~1200 px, светлая тема Windows 11):

| Файл | Что снять |
|---|---|
| `palette.png` | Палитра поверх, например, Блокнота с выделенным текстом с ошибками |
| `smartscreen.png` | Окно SmartScreen с раскрытой ссылкой «Подробнее» и кнопкой «Выполнить в любом случае» |
| `providers.png` | Настройки → «Провайдеры» с заполненным провайдером (ключ скрыт точками) |
| `prompts.png` | Настройки → «Промпты» с открытой командой |
| `preview.png` (по желанию) | Палитра в режиме превью с готовым результатом |

Не показывайте на снимках ключи и личные тексты.
