# Чистовик

[English version](README.en.md)

**Выделил текст → нажал хоткей → через секунду-две на том же месте лежит исправленный текст.** В любом приложении Windows: браузер, Word, Telegram, Блокнот, почта.

Чистовик — лёгкое приложение для Windows 10/11, которое работает с текстом через нейросеть (OpenAI, OpenRouter, DeepSeek, Groq, Ollama и любой OpenAI-совместимый сервис). Как браузерные расширения вроде MaxAI или Sider, только системное: работает везде.

> ⚠️ **Ранняя версия (0.1).** Основное работает, но возможны шероховатости. Сообщайте о проблемах в [Issues](../../issues).

![Палитра команд](docs/screenshots/palette.png)

## Что умеет

- **Палитра команд** по `Ctrl+Alt+Space`: исправить орфографию, улучшить, сократить, перевести RU↔EN, деловой/дружелюбный тон, списком и другие — 12 встроенных команд.
- **Свои команды:** название, иконка, текст промпта, своя клавиша и даже своя модель.
- **Разовая инструкция:** напишите в палитре, что сделать с текстом, и нажмите Enter.
- **Превью:** сначала посмотреть результат, потом «Принять» — или заменять сразу.
- **Несколько провайдеров** и выбор модели для каждой команды.
- **История:** что было и что стало, поиск, копирование. Хранится только у вас на компьютере.
- **Отмена последней замены** по `Ctrl+Alt+Z`.
- Русский и английский интерфейс, автозапуск, автообновление.

## Установка

1. Откройте [последний релиз](../../releases/latest) и скачайте файл `Chistovik_…_x64-setup.exe`.
2. Запустите его. Права администратора не нужны.
3. Windows может показать синее окно «Windows защитила ваш компьютер» — у приложения пока нет платного сертификата. Нажмите **«Подробнее» → «Выполнить в любом случае»**.

![SmartScreen](docs/screenshots/smartscreen.png)

## Первая настройка

1. После установки откроются настройки на вкладке **«Провайдеры»**.
2. Нажмите **«Добавить»** и выберите сервис (например, OpenAI) — адрес подставится сам.
3. Вставьте **API-ключ** и нажмите **«Проверить»** — подгрузится список моделей. Выберите модель и **«Сохранить»**.

Ключ хранится в **диспетчере учётных данных Windows**, а не в файлах. Для Ollama на этом же компьютере ключ не нужен.

![Настройки провайдера](docs/screenshots/providers.png)

## Как пользоваться

| Клавиши | Что делают |
|---|---|
| `Ctrl+Alt+Space` | Открыть палитру команд |
| `Ctrl+Alt+F` | Сразу исправить орфографию и пунктуацию |
| `Ctrl+Alt+Z` | Вернуть текст, который был до последней замены |
| `↑` `↓` `Enter`, цифры `1`–`9` | Выбор команды в палитре |
| `Esc` | Закрыть палитру или отменить запрос |

Выделите текст (или просто поставьте курсор в поле — тогда обработается всё поле) и нажмите хоткей. Клавиши команд и клавишу отмены можно поменять в настройках.

**Свой промпт.** Во вкладке «Промпты» нажмите «+ Новая». Напишите `{{text}}` там, где должен стоять выделенный текст; если не напишете, текст добавится в конец.

![Редактор команд](docs/screenshots/prompts.png)

## Приватность

- Текст отправляется только выбранному вами провайдеру нейросети.
- В журналы приложения текст не пишется. Локально он хранится только в истории — её можно выключить или очистить.
- Ключи — только в диспетчере учётных данных Windows.

## Сборка из исходников

Нужны Node.js 22+, Rust (stable) и [зависимости Tauri для Windows](https://tauri.app/start/prerequisites/).

```bash
npm ci
npm run tauri dev     # запуск для разработки
npm run tauri build   # установщик в src-tauri/target/release/bundle/nsis
```

Проверки: `npm test`, `npm run lint`, `cargo test --manifest-path src-tauri/Cargo.toml`. Подробнее — в [CONTRIBUTING.md](CONTRIBUTING.md).
